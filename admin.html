Prepare an updated resource catalogue for the public student portal.

Important — this is a file-preparation dashboard, not a live authenticated admin system. GitHub Pages is static hosting. This page does not sign you in, upload files to GitHub, or publish changes automatically. It prepares a resources.json file for you to download and commit to the repository. Do not enter passwords, tokens, or confidential data here.

Add or edit a resource

Catalogue entries

    After downloading, replace the repository's resources.json using GitHub's Add file / Upload files or Edit file workflow. Commit the change to publish it.

    Publishing checklist

    1. Upload PDFs/PPTs to the repository's files/ folder, or use stable public links.
    2. Set each resource URL to its relative path or public URL.
    3. Download the updated resources.json and commit it to the repository root.
    4. Wait for GitHub Pages to rebuild, then verify the public portal.
